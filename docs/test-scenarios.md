# 클라이언트 테스트 시나리오

## Item 컴포넌트

| # | 시나리오 | 기대 결과 |
|---|----------|-----------|
| 1 | 상품명, 가격, 수량을 props로 전달한다 | 상품명, 가격, 수량이 화면에 렌더링된다 |
| 2 | `+` 버튼을 클릭한다 | `onPlus`가 호출된다 |
| 3 | `−` 버튼을 클릭한다 | `onMinus`가 호출된다 |
| 4 | 삭제 버튼을 클릭한다 | `onDelete`가 호출된다 |
| 5 | 체크박스를 클릭한다 | `onSelectItem`이 호출된다 |
| 6 | `isSelected`가 `true`인 상태로 렌더링한다 | 체크박스가 체크된 상태이다 |
| 7 | `isSelected`가 `false`인 상태로 렌더링한다 | 체크박스가 체크 해제된 상태이다 |
